# SCRIPT-ROBLOX 

Ele funciona da seguinte forma.
Vc baixa o madium no pc, vai criar sua conta no madium,
quando for para criar vc vai pegar uma key (code) para
confirma a sua conta criada no madium.

Depois de Baixar Vc click em launch que ele vai iniciar
o roblox modificado (não precisa desistalar o roblox normal!).

E Depois Vai na aba scrips E Add O Code (script) e click Run (iniciar)
Mas tem que ta dentro do jogo que vc quer usar.
